# Dashboard

## Overview

The Hedgehog Dashboard is your central control panel for managing all your DeFi positions across protocols.

## Features

### Position Overview
- View all active positions across Aave, Uniswap, and other integrated protocols
- Real-time position values and performance metrics
- Health factor monitoring for borrowing positions

### Performance Metrics
- Total portfolio value
- Daily/weekly/monthly PnL
- APY calculations per position
- Fee earnings from LPs

### Automation Status
- See which strategies are enabled
- View recent bot executions
- Monitor automation performance

### Transaction History
- Complete history of all operations
- Filter by position, protocol, or date
- Export for tax reporting

## Quick Actions

- **Deploy Proxy** - Create your Hedgehog proxy
- **Create Position** - Supply, borrow, or LP
- **Enable Automation** - Turn on strategy execution
- **Emergency Exit** - Close all positions
