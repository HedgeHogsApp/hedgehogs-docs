## Repo layout (the renderer reads this)

```
hedgehogs-docs/
  content/
    index.mdx                  # the docs homepage (guide grid)
    meta.json                  # root navigation order
    get-started/
      meta.json                # section order + titles
      quick-start.mdx
      deploy-account.mdx
      dashboard-tour.mdx
    how-it-works/
      meta.json
      architecture.mdx
      proxy-model.mdx
      approvals.mdx
      automation.mdx
    portfolio/  lending/  liquidity/  automations/  protocols/  security/
      meta.json + *.mdx
  components/
    docs/                      # ported in-app animations (StrategyFlow…, Auto*)
    docs-ui/                   # sidebar, toc, prose, codeblock, callout, cards…
  lib/
    docs/                      # meta.json loading, sidebar/toc builders, slug utils
  pages/  styles/  public/
```

- `meta.json` per section: `{ "title": …, "order": [ "quick-start", … ] }` — the
  Uniswap `docs-content` pattern. Navigation and prev/next are derived from it,
  never hand-written in a component.
- **`/llms.txt`** — a static route: agent-readable markdown index of every page,
  per the llms.txt spec (Uniswap ships the same at `/llms.txt`). Per-page
  markdown is available at `/docs/<slug>.md` (or `Accept: text/markdown`).
- Pages that embed an animation are `.mdx` and import
  `@/components/docs/<Name>`.

## Editorial rules (inherited)

- **D2, always**: never describe an estimate as a measurement. A figure the app
  renders `—` is described as unavailable, not guessed.
- **One fact once**: a number that appears in the dashboard is not restated as a
  marketing boast in prose.
- **Worded, honest copy**: raw error strings never appear in instructions.
- Tone: refined, confident, calm under density — the product voice
  (`.impeccable.md`). No "revolutionizing DeFi" superlatives in usage pages.
