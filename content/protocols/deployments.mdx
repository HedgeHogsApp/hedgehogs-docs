The protocol is a set of contracts deployed per chain. Addresses live in the protocol's deployment scripts and are read by the app at runtime — the list below is the map, not the source.

## Per chain

| Chain | ID | Status |
|---|---|---|

| BNB Smart Chain | 56 | Live |

For the canonical, always-current address list (factory, directory, connectors, strategies, position reader), read the deployment output in the `hedgehogs-contracts` repository — `script/Deploy/NetworkConfig.sol` for the config, and the per-chain deployment JSON that the deploy scripts emit.

<Callout tone="warning" title="Always verify">
  In DeFi you interact with what the app points at. For anything you verify by hand, check the address against the contract deployment output for that chain — never against a screenshot or a forum post.
</Callout>
