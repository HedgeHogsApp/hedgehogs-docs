Beyond Aave and Uniswap V3, HedgeHogs integrates the protocols your positions already live on.

## Shipped connectors & strategies

| Protocol | What it offers | Chains |
|---|---|---|
| **Morpho Blue** | Supply, borrow, repay, collateral | Mainnet, Base |
| **Compound V3 (Comet)** | Supply, withdraw, claim, borrow, repay | Mainnet, Base |
| **Curve** | Stable swaps, add / remove liquidity, harvest | Mainnet, Base, BNB |
| **Balancer V2** | Join / exit pools, swaps, claim rewards | Mainnet, Base |
| **Yearn V3** | ERC-4626 vault deposits / withdrawals / redemptions | Mainnet |
| **PancakeSwap V3** | Concentrated LP + CAKE staking (MasterChef) | BNB, Base |
| **Aerodrome (Base)** | Swaps, LP, gauge staking | Base |
| **Aerodrome Slipstream** | Concentrated LP (UniV3-shaped) | Base |

Each protocol has its own stateless connector, so the account's approvals stay JIT per protocol and nothing new is needed to add a market.

<Callout tone="info" title="Roadmap">
  The connector architecture is built to add more (Curve v2, Pendle fixed-yield, more gauges). Markets appear in Explore automatically as deployments land.
</Callout>
